    Command examples¶

    One example of each change type, written as a KGCL command and as YAML. The examples are generated from the test suite (tests/cases.py), so every command on this page is known to parse. For before-and-after diagrams of the most common changes, see the visual guide to change types.

    Labels¶

    Rename a node (replace its label)¶

    Class: NodeRename

    rename GO:0005635 from 'nuclear envelope' to 'foo bar'

    id: CHANGE:001
type: NodeRename
old_value: nuclear envelope
new_value: foo bar
about_node: GO:0005635
about_node_representation: curie

    Add a label to an unlabeled node¶

    Class: NewLabel

    add label 'nucleus' to GO:0005634

    id: CHANGE:001
type: NewLabel
new_value: nucleus
about_node: GO:0005634
about_node_representation: curie
